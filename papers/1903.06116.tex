\subsection{Scaling attractors in multi-field inflation --- arXiv:1903.06116}

\textbf{Authors:} Perseas Christodoulidis, Diederik Roest, Evangelos I. Sfakianakis

\paragraph{主な主張}
曲がった場空間をもつ二場 inflation の scaling attractor を、Hubble flow parameter \(\epsilon\) が一定となる dynamical system の critical point として分類し、既知の geodesic / non-geodesic attractor を近似的な scaling solution として統一的に記述できることを示した \cite{Christodoulidis:2019scaling}。

\paragraph{新規性}
Scaling solution を多場 inflation の attractor を整理する共通の枠組みとして用い、geodesic motion から non-geodesic motion への移行に dynamical bifurcation が重要であることと、通常の安定性条件では背景発展を捉えきれない場合があることを明確にした。

\paragraph{位置付け}
双曲型の場空間を含む二場系で、potential の局所的な傾きと場空間 geometry から scaling attractor の存在・安定性・ゆっくり動く critical point への追従を調べる基礎文献であり、\(SL(2,\mathbb{Z})\) modular potential の radial direction が長く scaling を保てるかを調べる際の直接的な参考になる。
