\subsection{The Universal Extra Dimensional Model with $S^2/Z_2$ extra-space --- arXiv:0904.1909}

\textbf{Authors:} Nobuhito Maru, Takaaki Nomura, Joe Sato, Masato Yamanaka

\paragraph{主な主張}
6次元時空 $M^4\times S^2/Z_2$ 上に $SU(3)\times SU(2)\times U(1)_Y\times U(1)_X$ の UED 模型を構成し、$U(1)_X$ 背景ゲージ場によって $S^2$ の spin connection の効果を相殺して4次元の massless chiral fermion zero modes を得るとともに、各場の KK 展開と質量スペクトルを導出した \cite{Maru:2009S2UED}。

\paragraph{新規性}
通常の toroidal UED とは異なる $S^2/Z_2$ compactification で SM zero-mode spectrum と KK parity を両立する具体的な6次元模型を与え、背景 flux を fermion zero mode の生成機構として組み込んだ点にある。

\paragraph{位置付け}
$S^2$ with flux 上の fermion KK tower を具体的に扱う先行研究として特に直接的であり、$Q=1/2$ の背景では fermion spectrum が $M_l^2=l(l+1)/R^2$ となって $l=0$ zero mode が復活するため、$T^2$ bulk-neutrino 模型を spherical compactification と比較する際の基準文献である。
