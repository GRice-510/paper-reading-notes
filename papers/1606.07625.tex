\subsection{Effect of compactification of twisted toroidal extra-dimension on sterile neutrino --- arXiv:1606.07625}

\textbf{Authors:} Ajit Kumar Mohanty

\paragraph{主な主張}
twisted $T^2$ の shape angle $\theta$ が KK mass gap と level crossing を変えることで active--sterile mixing が強く形状依存し、最初の2つの低い KK 状態では重い方の状態がより強く混合する領域が存在し、その特徴が reactor antineutrino spectrum の Fourier 解析に現れ得ることを示した \cite{Mohanty:2016twisted}。

\paragraph{新規性}
トーラスの shape modulus が KK spectrum を変えるという既知の効果を bulk sterile neutrino に具体的に適用し、幾何学的な KK level crossing と neutrino oscillation phenomenology を結び付けた点が新しい。

\paragraph{位置付け}
$T^2$ LED sterile-neutrino phenomenology の直接的な先行研究である一方、主な観測的議論は最初の2つの KK 状態と reactor spectrum に限られており、full KK tower の Earth-matter propagation や IceCube 型の高エネルギー大気ニュートリノ解析までは扱っていない。

\paragraph{コメント}
被引用数は0とされているが集計元は要確認であり、SciRate に表示される ``0'' は citation count ではなく scite 票なので、この数字だけを被引用0の根拠にはできない。また、以下は本文を標準的な $T^2$ compactification として読んだ際の要確認点であり、直ちに論文全体の誤りを意味するものではない。
\begin{itemize}
  \item KK モードの列挙では $(1,-1)$ 型の符号の異なる格子点が見えず、追加の射影や境界条件が無い通常の $T^2$ なら縮退度を過小評価している可能性がある。
  \item トーラス面積および KK mass formula の $\sin\theta$ 依存は通常の幾何学的半径の規約とそのままでは整合しないように見え、誤植・半径の再定義・規約の説明不足を区別して再導出する必要がある。
  \item 二次元 KK tower の和は対数的に UV sensitive であり、absolute active weight や full oscillation probability を定量予言するには cutoff / UV completion の扱いが必要である。この対数発散自体は本文でも認識されている。
  \item phenomenology は主に最初の2つの KK 状態を $(3+2)$ 模型になぞらえた比較と reactor Fourier spectrum に留まり、full tower、全フレーバー、global-fit tension、detector-level likelihood までの整合性は検証されていない。
\end{itemize}
