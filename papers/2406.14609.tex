\subsubsection{On small Dirac neutrino masses in string theory --- arXiv:2406.14609}

\textbf{Authors:} Gonzalo F. Casas, Luis E. Ibáñez, Fernando Marchesano

\paragraph{主な主張}
4次元 $\mathcal{N}=1$ type IIA Calabi--Yau orientifold の infinite-distance limit では、右巻きニュートリノの kinetic term が $K_{\nu\nu}\sim g_\nu^{-2}$ と増大することで $m_\nu\simeq g_\nu\langle H\rangle$ の小さな Dirac 質量が得られ、同時に $m_0\sim g_\nu^2M_{\rm P}\simeq0.1$--$500\,{\rm eV}$ の $\nu_R$-like tower と2つの large hidden dimensions が現れることを示した\cite{Casas:2024Dirac}。

\paragraph{新規性}
tiny Dirac neutrino Yukawa、非常に弱い massive $U(1)$ gauge coupling、Swampland の light tower と decompactification を同一の asymptotic regime に結び付け、1次元または2次元を超える large dimensions では phenomenological difficulties が生じるため2 large dimensions が特別に選ばれ得ることを論じた。

\paragraph{位置付け}
2次元 large-extra-dimension neutrino 模型に string-theoretic UV motivation を与える研究であり、$T^2$ の complex structure による KK spectrum の形状依存そのものは扱わないが、ニュートリノ部門だけが感じる2つの large dimensions と light tower が自然に現れ得ることを示している。
